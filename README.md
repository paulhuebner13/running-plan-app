# Sport App v59 — Half marathon 1:40 progression

Based on v58. The plan keeps four runs per week and approximately 35 km with cutback weeks.
The fixed calendar progression remains active even if feedback is `Okay`: the interval and threshold paces gradually improve across the season. The seven-stage slider then calibrates future runs of the same type up or down. Easy and long runs remain effort/HR-focused and are not forced to become faster.

The HM goal is now sub-1:40 (~4:44/km), including race pacing and final HM-specific sessions. This is an ambitious target, not a guarantee; adjust through the slider if the workouts feel too hard/easy.

No change to Gym, visual design, Supabase schema or the feedback UI.
