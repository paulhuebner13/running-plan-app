Sport App v32

Changes:
- Running/Gym switch at the bottom.
- Gym page with two weekly workouts.
- Gym overview page via calendar button.
- Exercise cards with color coding: Push yellow, Pull red, Legs blue.
- Exercises can be checked individually.
- Gym workout is automatically done when every exercise is done.
- Each exercise opens a detail page with explanation, alternatives, and a timer.
- Timer phases: 10s preparation before every set, work phase, rest phase.
- Timer supports play, pause, reset, and draggable progress point on the circle.
- Tibialis exercise is named Tibialis Raises and includes cable/foot strap plus alternatives.
